# 阅览室 · X Top Threads

Editorial directory of top X articles & threads from the past year across Agent / AI / OPC / Writing / Taste / Marketing / Monetization.

## Live

https://davidliu12-code.github.io/x-top-threads/

## Stack

- Vite + React + TypeScript + Tailwind
- Geist / Geist Mono
- Visual system inspired by [阅览室 · X Top 100](https://xtop100-2026.vercel.app/)
- UI unslopped with https://github.com/heydamir/unslop (CC BY 4.0 · Damir Sokolovsky)

## Features

- Ranked editorial list (not card grid)
- Domain / type filters, search, multi-sort
- ZH / EN bilingual + invert theme
- Data: `public/data/items.json` (105 items)

## Develop

```bash
npm install
npm run dev
npm run build
```

GitHub Pages serves from `docs/` with base `/x-top-threads/`.
